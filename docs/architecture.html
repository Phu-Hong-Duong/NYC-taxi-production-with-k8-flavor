4 · The four laws that hold it together

One storage story

MinIO's S3 API serves data, DVC, MLflow artifacts, Flyte metadata, and KServe model pulls. Learn one interface, reuse it five times — swap in real S3 later by editing a values file.

One DAG owner

Flyte orchestrates everything; DVC versions data but never orchestrates. Two DAG owners in one repo is a confusion tax this project refuses to pay.

One features path

Training and serving import the same transform functions, so train/serve skew is structurally hard — and the serving parity test (offline == online within 1e-6) proves it anyway.

One gate, no side doors

Champion moves only on held-out-month evidence: not for the hand-built model, not for AutoML's best, not for Optuna's. Gates loosen only by your decision as PO.
