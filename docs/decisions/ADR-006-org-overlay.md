# ADR-006 — Enterprise org simulation, platform-shaped (not bank-shaped)
- Status: accepted
- Date: 2026-08-12
- Context: principal's re-scope, quoted verbatim in BLUEPRINT §2 ("how data
  engineer, data analyst, machine learning engineer and ML ops technique blending
  together ... I want to see how they work together in tandem"), plus standing
  latitude grant ("Feel free to add, change or modify as you wish ..."). "SLE"
  interpreted as SRE (flagged in BLUEPRINT §2; reopens if misread).
- Options: (a) copy predecessor's bank geometry (MRM/CO/IA) · (b) platform
  geometry: SRE rituals + one Staff Reviewer · (c) no org overlay.
- Choice: (b). Same separation principle as the predecessor (builder/challenger/
  assurer, fresh-eyes review, mandatory finding, no self-sign-off) in the
  industry-correct form for a mobility platform (SLOs, PRR, gamedays,
  postmortems). Predecessor org docs read 2026-08-12 from the connected repo.
- Honest cost: ~+20-30% session time per milestone; accepted scope per mandate.
- Revisit trigger: a ritual that stops earning its minutes -> PO fork to cut it.
